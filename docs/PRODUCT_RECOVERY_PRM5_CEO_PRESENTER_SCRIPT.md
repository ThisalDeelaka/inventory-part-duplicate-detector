# PRM-5 CEO Presenter Script

## 0:00-0:35 - Dashboard

"Inventory teams often suspect duplicate parts, but similarity alone is not a
safe operational decision. This dashboard keeps every scan visible, so we can
start a new scan or reopen a saved result without losing our place."

## 0:35-1:45 - Optional small live scan

"I will use a 17-row synthetic file to show the real upload path without making
the meeting wait for a full-inventory run. We map the fields, validate the file,
and run it. The product tells us when validation passes and shows an honest
processing state and elapsed time."

If the small scan is slow, omit it: "The live illustration is optional, so I'll
move directly to the saved full-inventory result."

## 1:45-2:55 - Saved full result

"This is the pre-completed 5,327-record result, reopened from normal history. It
contains 203 candidate groups: 114 stronger Likely hypotheses and 89 groups that
need more review. Conflicts and Deferred work are separate because the system
does not turn contradictory or incomplete evidence into a duplicate conclusion.
These are system-generated review hypotheses, not ground truth."

## 2:55-4:05 - Explanation

"Opening one group shows the records together. The System explanation translates
persisted evidence into plain language: why the group was surfaced, the strongest
supporting points, and the cautions. Advanced evidence is available, but the
reviewer does not have to begin with raw technical data."

## 4:05-5:10 - Human decision

"The machine does not silently become operational authority. A reviewer can
Confirm, Reject, or Defer. I'll confirm this disposable example; the important
saved full result remains unchanged. Reject means the proposed set is not
accepted. Defer means the decision is intentionally left unresolved."

## 5:10-5:50 - Human authority

"The System explanation stays visible, while the Human decision section shows
the current decision and preserves earlier decisions in history. That separation
makes it clear what the system suggested and what a person authorized."

## 5:50-6:35 - Exports

"The System Group Export contains machine-generated suggestions for analysis.
The Reviewed Identity Export is deliberately different: it contains only current
human-confirmed identity sets. If no set has been confirmed, the product says so
instead of quietly exporting unreviewed suggestions as approved truth."

## 6:35-7:00 - Close

"The value is a controlled workflow: discover, explain, review, confirm, export.
This is a showable human-in-the-loop product. We are not claiming validated
autonomous accuracy; that requires the separate deferred human-label program.
Today, the product makes suspicious inventory identity work understandable,
reviewable, recoverable, and operationally explicit."
